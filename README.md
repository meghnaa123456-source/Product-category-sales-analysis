📊 Product Category Sales Analysis using Python
📌 Project Overview
This project focuses on analyzing product category sales using Python. The main goal is to understand sales performance, customer preferences, payment methods, and monthly sales trends through data cleaning, exploratory data analysis (EDA), and data visualization.
🎯 Project Objectives
- Analyze sales based on product categories.
- Identify popular product categories and products.
- Calculate and understand sales performance.
- Analyze monthly sales trends.
- Understand customer payment preferences.
- Visualize data using Python libraries.
📂 Dataset Information
- Dataset: Product Category Sales
- Total Rows: 11,904
- Total Columns: 9
Dataset Columns
1. Invoice_ID
2. Date
3. Category
4. Product
5. Gender
6. Quantity
7. Unit_Price_Rs
8. Total_Sales_Rs
9. Payment
🛠️ Technologies & Libraries Used
- Python
- Pandas – Data manipulation and cleaning
- NumPy – Numerical operations
- Matplotlib – Data visualization
- Seaborn – Statistical visualization
🧹 Data Cleaning & Preprocessing
The following data cleaning techniques were performed:
- Checked and removed duplicate records.
- Handled missing values.
- Converted Date into datetime format.
- Converted Quantity and Unit Price into numeric formats.
- Filled missing categorical values using mode.
- Filled missing numerical values using mode or median.
- Standardized text values by removing extra spaces and correcting capitalization.
- Checked missing values after cleaning.
📈 Exploratory Data Analysis (EDA)
1. Univariate Analysis
- Histogram – Distribution of transaction sales.
- Count Plot – Product category distribution.
- Count Plot – Payment method distribution.
2. Bivariate Analysis
- Box Plot – Category-wise sales distribution.
- Line Plot – Monthly sales trends.
3. Multivariate Analysis
- Heatmap – Correlation between Quantity, Unit Price, and Total Sales.
💡 Key Business Insights
1. Most transactions have lower sales values, while a few transactions have higher sales values.
2. The Food category has a higher number of transactions compared to Beverages.
3. Customers use different payment methods, including Cash, UPI, and Card.
4. The box plot shows outliers in both Food and Beverages categories.
5. Monthly sales show variations throughout the year.
6. The heatmap shows a positive relationship between Unit Price and Total Sales.
📌 Conclusion
This project helped analyze product sales, customer preferences, and monthly sales trends using Python. Data visualization and exploratory data analysis provided useful insights that can support better business decisions.
